# 源码策划注释归档

玩法参数、行为规则和设计意图放在 Markdown 中，Java 源文件保留可执行代码与必要技术注释。本次迁出 19 个既有 Java 文件中的 55 条策划／玩法说明，不改变对应文件的可执行词法 token。

- [迁出注释原文与源位置](planning-notes.md)
- [迁移清单与代码 token 摘要](comment-migration.json)
- [当前月伤规则](../moon-damage/current-rules.md)

保留原有 API 文档、技术算法说明、版权、TODO、分类标签和历史注释代码；它们不属于本轮策划注释迁移范围。原注释并不一定准确，档案中单独标明了浮岛草概率“注释 20%、代码 10%”的已有差异，本轮没有改动该玩法。

从仓库目录运行：

```sh
python3 docs/gameplay/source-notes/verify_comment_migration.py
```

验证器忽略 Java 注释和注释外空白，同时保留字符串、字符、文本块、标识符和运算符，对照迁出前摘要检查这 19 个文件。它只验证此次注释迁移未更改可执行 token，不代替 Java 编译或其他业务测试。以后如有意修改这些文件的业务逻辑，旧摘要就不再适用于该文件，需要在正常代码评审中更新验证范围，而不能为了让检查通过随意刷新摘要。
