# 当前月伤实施规则

本文件收敛截至 2026-10-25 已确认的策划，以及本轮实施采用的边界裁定。历史方案和算例保留在同目录，不能覆盖本文件。实际验证结果随本轮代码交付记录，不把静态伤害算例视为完整游戏服实测。

## 伤害与武器档位

月伤原始补伤 `E = 附魔等级 × 武器倍率 × 昼夜倍率 HP`，不再乘武器本次实际伤害，不额外随蓄力或暴击缩放。原武器本体、力量和锋利仍按各自原版流程结算。

| 武器档位 | 月伤倍率 | 对玩家第五次可转真伤 |
| --- | --- | --- |
| 原版木／金 | 0.6 | 否 |
| 原版石 | 0.65 | 否 |
| 原版铁 | 0.75 | 否 |
| 原版钻石 | 0.9 | 是 |
| 原版下界合金 | 1 | 是 |
| 下界铂金剑 | 1 | 是 |
| 死神镰刀 | 1 | 是 |
| 其他模组／未知武器 | 0.9 | 是 |

原版同材质的斧等武器复用对应剑档位，低档武器不能通过武器种类绕过玩家真伤资格。上述规则只决定已经符合月伤攻击条件的武器补伤，不把任意物品自动变成月伤武器。冈格尼尔保留 LTS 三叉戟玩法，未单列的月伤数值按模组通用钻石档。

## PvP 与 PvE

- 对非玩家：每次月伤为 `E` 真伤；窗口内第五次替换为 `1.25E` 真伤，不叠加另一份普通月伤。
- 对玩家：通常为 `E` 普通伤害，加入同一次主目标攻击后统一减伤。符合资格的第五次替换为 `min(2 HP, 0.75E)` 真伤。
- 玩家真伤最后封顶。合金档月伤 III 夜晚理论 2.25 HP，封顶 2 HP；非夜晚为 1.125 HP，保持该值。
- 玩家第五次若仍在该武器真伤冷却中，结算普通月伤并重新计数，不停在四层等待，不储存补发真伤。
- 整套四件下界铂金护甲使月伤普通原始补伤乘 0.75；不足四件不生效，不减武器本体或月伤真伤。依服务端真实物品判断，不依据 Polymer 客户端展示物品判断。

## 状态只绑定具体武器

所有状态属于服务端识别的具体武器实例，不属于武器种类、快捷栏或攻击者：

| 状态 | 键与规则 |
| --- | --- |
| 玩家连击 | 具体武器＋目标玩家，每个目标分别统计 |
| 非玩家连击 | 具体武器，允许跨怪累计 |
| 玩家月伤间隔 | 每武器至少 6 tick，对所有玩家目标共享 |
| 非玩家月伤间隔 | 每武器至少 1 tick，跨怪共享 |
| 玩家第五次真伤冷却 | 每武器 30 tick，对所有玩家目标共享 |

PvP 和 PvE 的间隔与计数分开。非玩家不受玩家 30 tick 真伤冷却影响。武器转交后允许继承层数与剩余冷却，时间继续流逝；单人轮换多把武器利用独立冷却是明确允许的玩法，不增加攻击者全局限制或切武器惩罚。

不同武器不能共享实例身份。正常损耗耐久或改名不改变实例身份；月伤等级或档位变化使旧档位连击失效，但不刷新已存在冷却。短期运行状态不持有实体／世界引用；物品复制与状态清理须验证，不能靠永久缓存实现。

## 计数、时间与攻击范围

- 采用滚动 60 游戏 tick 窗口，跨度恰好 60 tick 仍包含；第五次消费整组并清空。不会每次命中刷新整个截止时间、无限续期。
- 一次有效近战主目标攻击只计一次。挥空、完全格挡、被服务器伤害保护拒绝的攻击不补月伤、不计数；吸收生命抵扣导致红血不变不能直接判无效。
- 未达到相应 6／1 tick 间隔时不补伤、不计数；恰好达到间隔允许触发。恰好经过 30 tick 允许玩家真伤。
- 日夜倍率：主世界日内刻度 `[13000, 23000)` 为夜晚，倍率 1；其他时间 0.5。下界和末地等维度统一参照主世界时刻。
- 连击与冷却使用统一的单调服务器 tick；不使用可被睡觉或 `/time set` 修改的日夜时间。不因持有者转交、重连或换世界刷新武器冷却。
- 目标玩家死亡／重生、断线或跨世界后，不继承该目标旧一轮连击；PvE 目标死亡不清除武器的跨怪计数。
- 不增加第五次或冷却的音效、粒子、提示。

主接入范围是直接近战主目标：普通补伤在原攻击中合并，月伤额外伤害不重入月伤计数。投掷、弹幕、火焰、荆棘与扫击副目标不因主手持月伤武器自动触发；可接入同类近战主目标流程的 NPC 使用相同规则，具体覆盖与验证结果以实现记录为准。

## 受伤保护、吸收与死亡

保留对应月伤近战连续命中手感，但不清零目标公共 `lastHurt` 等状态给其他伤害来源开窗。月伤补伤间隔不能被实现成整次普通攻击的冷却。

真伤保持旧直接扣血的防御／吸收绕过性质，但在同一次原生伤害链中处理归因、生命、死亡和图腾，不另打一笔伤害追杀本次已被图腾救回的目标。不得直接照抄旧版“生命不足附魔等级就跳过扣血”，也不得借真伤擅自绕过完全格挡、创造／旁观、友伤关闭或其他服务器拒绝伤害的判断。
