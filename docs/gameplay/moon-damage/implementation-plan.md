# 月伤武器状态与伤害链实施计划

**目标：** 在 Minecraft 1.21.8 Fabric LTS 中实现已确认策划，保留 Polymer 与原武器玩法，提交到用户 fork 的工作分支，不创建 PR。

**结构：** 纯 Java 武器状态机负责滚动窗口、武器独立间隔与玩家真伤冷却；服务端适配层负责真实物品身份、档位和生命期；主目标近战上下文在原伤害链中合并正常补伤与真伤，避免第二次伤害和重复图腾处理。策划解释与注释统一存于 docs/gameplay/，源文件不新增策划注释。

**基线：** b70aacb6a9fed5200d8834531b87772483521f68，包含此前已验证的音乐修复和键盘 Dialog，先独立提交保存。

## 固定规则

- 武器倍率木/金0.6、石0.65、铁0.75、钻石0.9、合金/铂金1；原版其他同材质武器复用档位，未识别/模组武器按钻石，死神镰刀按合金。
- 补伤=等级×档位×昼夜；夜1、其他0.5，不按攻击蓄力/暴击再缩放。
- 所有状态绑定具体武器；转交保留层数和冷却；不同武器独立，允许轮换，不设攻击者全局限制。
- 玩家每武器间隔6 tick，连击按武器+目标；非玩家间隔1 tick，每武器跨目标累计；三秒滚动窗口60 tick、第五次消费整个窗口。
- 非玩家每次真伤，第五次乘1.25；玩家仅钻石/合金档第五次转真伤，min(2,补伤×0.75)，每武器对所有玩家共享30 tick冷却，冷却中的第五次回退普通月伤并清零。
- 铂金完整四件只让普通月伤原始额外补伤乘0.75。
- 一次有效主目标近战一次计数；不通过清零目标公共受伤字段保留连续命中；正确处理盾牌、取消、吸收、致死、图腾及死亡/断线/换世界。

## 具体裁定

- 沿用已比较的 master 时段：统一取主世界日内时间 [13000,23000)，跨维度一致；冷却只用单调服务器 tick，不使用日夜时间。
- 滚动窗口包含跨度恰好60 tick；间隔在 elapsed>=限制时允许。
- 真伤继承旧版绕过吸收生命的性质，但不跳过标准伤害拒绝、友伤、盾牌和一次死亡/图腾处理；不另调用第二次 hurt。
- 攻击使用实际命中武器快照；月伤等级或档位改变时清连击，不刷新既有冷却；耐久/改名不清连击。
- 原攻击链按近战主目标接入；投掷/弹幕/火焰/扫击副目标不新增月伤触发。NPC近战在相同主目标接口可接入时复用规则，不将主手附魔扩散到任意伤害。
- 武器只持久化服务端身份，不在每次命中修改物品层数以引发同步；短期状态不持有实体或世界引用，过期及停服清理。
